# Security

To report a vulnerability, email [security@nubl.ai](mailto:security@nubl.ai).

Do not paste private keys, mnemonics, API tokens, or Cloudflare secrets in the email. Describe the component (`packages/contracts`, `packages/relayer`, `packages/relayer-client`, `packages/wallet`, or `packages/proto`) and the impact.

`packages/relayer/docs/SECURITY_AUDIT.md` is an older relayer review, not the reporting process.
