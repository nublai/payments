# Security

To report a vulnerability, open a GitHub issue on [giuseppecrj/Agentic-Payments](https://github.com/giuseppecrj/Agentic-Payments). This repo has no separate security contact email.

GitHub issues are public. Do not paste private keys, mnemonics, API tokens, or Cloudflare secrets in the issue. Describe the component (`packages/contracts`, `packages/relayer`, `packages/relayer-client`, `packages/wallet`, or `packages/proto`) and the impact.

`packages/relayer/docs/SECURITY_AUDIT.md` is an older relayer review, not the reporting process.
