# @agentic-payments/proto

Protobuf messages used by the wallet for login and session device material:

- `BearerToken`
- `WalletSessionToken`
- `ExportedDevice`

Source is `schema/payments.proto`. The package entry exports `BearerTokenSchema`, `WalletSessionTokenSchema`, `ExportedDeviceSchema`, and the `ExportedDevice` type.

The protobuf package is `payments`.
