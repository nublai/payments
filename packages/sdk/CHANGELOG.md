## 3.2.0

### Minor Changes

- [#611](https://github.com/HereNotThere/chat/pull/611) [`1f9cee5`](https://github.com/HereNotThere/chat/commit/1f9cee5b71b71b95e4d662576bd29c68c785241d) Thanks [@miguel-nascimento](https://github.com/miguel-nascimento)! - Add `ConversationSeed` and `ConversationSeedResponse` as first-class timeline event types

  Conversation seeds and seed responses are now parsed into dedicated `RiverTimelineEvent.ConversationSeed` and `RiverTimelineEvent.ConversationSeedResponse` timeline events instead of being treated as generic `ChannelMessage` events. This gives consumers typed access to seed fields (proposals, query, responseText, etc.) and response fields (selectedProposal, userMessage).

### Patch Changes

- [#644](https://github.com/HereNotThere/chat/pull/644) [`9a81d8c`](https://github.com/HereNotThere/chat/commit/9a81d8cb114d0e870b76de4a6af7589ea918801a) Thanks [@miguel-nascimento](https://github.com/miguel-nascimento)! - Auto re-authenticate on expired session token

  `AppRegistryService.createClient()` now returns a self-healing client that catches UNAUTHENTICATED errors, re-authenticates, and retries the call. Fixes long-running agents losing their session after token expiry.
