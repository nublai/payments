# Install and quickstart

Run the wallet CLI from a checkout of this repo. From the repo root:

```bash
bun install
bun run --cwd packages/contracts build
bun run --cwd packages/relayer-client build
cd packages/wallet && bun ./src/cli.ts --help
```

`@nubl/wallet` is not on npm yet. Commands below are `bun ./src/cli.ts <cmd>` from `packages/wallet`, after the builds above. Once the package is published, the command is `nubl <cmd>`. `bun link` from `packages/wallet` puts that command on `PATH` after `bun run build` in that package.

Every command that talks to a chain requires `--env prod`, `--env stage`, or `--env dev`. Omitting `--env` fails. There is no default environment.

`prod` defaults to chain `base` (8453). `stage` defaults to `base-sepolia` (84532). `dev` defaults to local Anvil (`anvil`, 31337). Override with `--chain base`, `--chain polygon`, `--chain anvil`, or `--chain base-sepolia`. The zero fee ceiling is signed only on chain ids 31337 and 41337. `--env dev` cannot sign payments on a published chain, including `--chain base` and Base Sepolia, because that env pays with the zero address, and off those two chain ids the payer and payment token must not be zero. Use `--env stage` for Base Sepolia and `--env prod` for Base.

## Create an account and send

`account create` writes a local keystore and delegates the account. The session it installs is narrow: this chain's USDC `transfer` (`0xa9059cbb`) and `approve` (`0x095ea7b3`), Escrow `escrow` (`0x657061bf`), `refund` (`0x6023fda5`), and `settle` (`0xe7f921a2`), and SimpleSettler `write` (`0x84523a30`), with 10 USDC per day. A chain with no known USDC or Escrow address is refused. An interactive terminal must type `CREATE FULL ACCESS SESSION`. `NUBL_PASSWORD` does not replace that phrase.

`account create --env dev` and `send` are not a local quickstart by themselves. Create reads chain 31337 addresses from the environment, and those keys are not in `addresses.json`. Send fails when the new account has no USDC.

From the repo root, the local create-and-send is:

```bash
bun run e2e:local-payment
```

Ports 8545, 8546, and 8787 must be free. The script starts Anvil, runs `deploy:local` and `make-config`, then exports each `NAME=0x…` line from `packages/contracts/deployments/envs/local/.env`. It starts the relayer, runs `bun ./src/cli.ts account create --env dev` from `packages/wallet`, mints with `packages/wallet/scripts/fund-dev.sh <account> 25`, and runs `bun ./src/cli.ts send 1 <recipient> --env dev`. It types `CREATE FULL ACCESS SESSION` and `SEND USDC`. See [Local development](/local-development).

`send` takes the USDC amount, then the recipient address or ENS name. An interactive terminal must type `SEND USDC`.

## Commands

`account`, `session`, `daemon`, `permissions`, `escrow`, `send`, `swap`, `bridge`, `address`, `login`, `logout`.

Structured output is `--format json` (also `toon`, `yaml`, `md`, or `jsonl`). `--json` is a global shorthand for `--format json` on every command.

`NUBL_PASSWORD` supplies the keystore password. It does not confirm a send, a private-key export, a session export, a full-access session or permission change, a passkey, escrow create or refund, or an oracle-key escrow settle. Commands that accept `--password-stdin` can read the password from stdin.

```bash
bun ./src/cli.ts session list --env prod --profile agent --format json
```

`bun ./src/cli.ts --help` lists commands. `bun ./src/cli.ts send --help` lists one command. `bun ./src/cli.ts --llms` prints the machine-readable manifest. `bun ./src/cli.ts --version` prints the version. `bun ./src/cli.ts --mcp` starts the stdio MCP server. See [MCP](/mcp) and [Security model](/security).
